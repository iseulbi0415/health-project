개인정보 처리방침

소담 (SoDam)

시행일: 2026년 8월 8일

소담은 이용자의 개인정보를 소중히 다루며, 앱 기능 제공에 필요한 최소한의 정보만 수집합니다. 본 방침은 소담이 어떤 정보를 어떤 목적으로 수집하고, 어떻게 보관·파기하는지를 설명합니다.

1. 수집하는 정보

구분 항목 수집 방법
계정 정보 카카오 회원번호 또는 Apple 사용자 식별자, 닉네임 소셜 로그인 시
신체 정보 키, 체중, 나이, 성별, 활동량 이용자가 직접 입력
이용 기록 식단 기록, 러닝 기록, 컨디션 메모, 즐겨찾기 이용자가 직접 입력

수집하지 않는 정보

  • 이메일 주소, 전화번호 등 연락처 정보
  • 위치 정보
  • 주소록, 사진, 마이크 등 기기 내 데이터
  • 광고 식별자 및 이용자 추적을 위한 정보

2. 이용 목적

  • 계정 정보 — 로그인 및 이용자 구분
  • 신체 정보 — 기초대사량, 목표 칼로리, 러닝 소모 칼로리 계산
  • 이용 기록 — 이용자 본인의 기록 저장 및 조회

수집한 정보는 위 목적 외의 용도로 이용하지 않으며, 마케팅이나 광고 목적으로 활용하지 않습니다.

3. 제3자 제공 및 처리 위탁

소담은 이용자의 개인정보를 제3자에게 제공하거나 판매하지 않습니다.

다만 앱 기능 제공을 위해 아래 외부 서비스를 이용합니다.

서비스 전달되는 정보 목적
카카오 / Apple 로그인 인증 정보 소셜 로그인
식품의약품안전처 식품영양성분DB 이용자가 입력한 음식 검색어 영양성분 조회
Anthropic Claude API 음식명 및 영양성분 후보 목록 1인분 기준량 추정
Railway 서버 및 데이터베이스 호스팅 데이터 저장
외부 API에는 음식 검색어와 영양성분 정보만 전달되며, 계정 정보·신체 정보·이용 기록 등 개인을 식별할 수 있는 정보는 함께 전송되지 않습니다.

4. 보유 기간 및 파기

수집한 정보는 이용자가 계정을 삭제할 때까지 보관하며, 계정 삭제 시 아래 정보가 즉시 완전히 삭제됩니다.

  • 계정 정보 및 신체 정보
  • 식단 기록, 러닝 기록, 컨디션 메모, 즐겨찾기 전체

삭제된 정보는 복구할 수 없으며, 별도의 백업본을 보관하지 않습니다.

5. 계정 삭제 방법

앱 내에서 직접 계정을 삭제할 수 있습니다.

  • 내 정보 탭 → 하단 회원 탈퇴 → 확인

계정 삭제 시 소담 서버의 데이터가 모두 삭제되며, 카카오 및 Apple 계정과의 연결도 함께 해제됩니다.

6. 이용자의 권리

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

  • 앱 내에서 본인의 기록을 조회·수정·삭제
  • 신체 정보 수정
  • 계정 및 전체 데이터 삭제 (회원 탈퇴)

7. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화하여 전송합니다.
  • 이용자별 데이터는 계정 식별자로 분리되어, 다른 이용자의 기록에 접근할 수 없습니다.
  • 인증 정보와 API 키는 코드에 포함하지 않고 서버 환경변수로 관리합니다.

8. 만 14세 미만 아동

소담은 만 14세 미만 아동을 대상으로 하지 않으며, 해당 연령의 개인정보를 의도적으로 수집하지 않습니다.

9. 의료 관련 고지

소담은 식사와 운동 기록을 돕는 도구이며 의료기기가 아닙니다. 질병의 진단·치료·예방을 목적으로 하지 않습니다. 앱이 제공하는 소화 대기 시간은 공개된 임상 가이드라인과 위 배출 연구를 참고해 산출한 참고값이며, 증상이나 복용 중인 약에 대한 결정은 반드시 의료 전문가와 상담하시기 바랍니다.
